# Python for Data Science — Foundations

A beginner-friendly learning repository covering the fundamentals required for an introductory Data Science internship.

## Tasks Covered

- Python installation and notebook environment setup
- Variables and basic data types
- Lists and dictionaries
- Loops and conditional statements
- Functions
- File handling
- Introduction to Data Science concepts
- Real-world Data Science applications
- A small practice exercise using sales data

## How to Run

### Option 1: Google Colab
1. Open Google Colab.
2. Upload `Python_for_Data_Science_Foundations.ipynb`.
3. Run the cells from top to bottom.

### Option 2: Jupyter Notebook
Install Python, then install Jupyter Notebook:

```bash
pip install notebook
```

Start Jupyter:

```bash
jupyter notebook
```

Open the `.ipynb` file and run the cells.
